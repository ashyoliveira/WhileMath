# WhileMath

Uma aplicação interativa de tabuada desenvolvida para explorar a lógica de
repetição com `while` e a manipulação de elementos da página com JavaScript.

## 📌 Objetivo

Transformar uma operação matemática simples em uma aplicação interativa,
praticando a construção da lógica por trás de cada resultado.

## 📌 Tecnologias

- HTML5
- CSS3
- JavaScript

## 📌 Conceitos explorados

- Funções
- Variáveis
- Condicionais
- Estrutura de repetição `while`
- Manipulação do DOM
- `innerHTML`
- Entrada e exibição de dados

## 📌 Como funciona

O usuário informa um número e a aplicação percorre os multiplicadores de 0 a 10,
gerando sua respectiva tabuada dinamicamente na página.
